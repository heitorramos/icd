# Aula 11 — Bootstrap

Exemplo baseado no dataset público **New York City Airbnb Open Data**, disponível
no Kaggle sob licença CC0.

Arquivos:

- `notebook.qmd`: análise descritiva e implementação didática;
- `generate_figures.py`: geração reproduzível das figuras dos slides.

Pergunta central: diferença entre os preços medianos de acomodações inteiras em
Manhattan e Brooklyn.
