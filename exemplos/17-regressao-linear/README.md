# Aula 17 — Regressão linear simples

Este diretório contém o material de estudo da Aula 17. O notebook desenvolve a regressão linear simples por mínimos quadrados, usando as despesas médicas como resposta e a idade como preditor.

- `notebook.qmd`: guia teórico e computacional autocontido;
- `generate_figures.py`: geração das figuras usadas nos slides;
- dados: reutilizados de `../16-correlacao/data/insurance.csv`.

O material não usa a interpretação geométrica por projeções. Máxima verossimilhança e gradiente descendente são apenas anunciados, pois serão tratados nas aulas seguintes.
