# Aula 06: tendências centrais

Notebook documentado para a Aula 06, usado como exemplo oficial de sala e como
material de estudo para os alunos.

## Papel didático

O exemplo usa o dataset Billboard Hits Songs, disponível no Kaggle em
`dem0nking/billboard-hits-songs-dataset`, para discutir como inspecionar uma
base, visualizar uma coluna numérica e escolher resumos adequados.

O CSV não é redistribuído neste repositório. O notebook baixa a base com
`kagglehub.dataset_download(...)`, usando o identificador oficial do dataset.

## Conceitos

- amostra e população;
- análise descritiva básica;
- pipeline descritivo;
- histograma;
- CDF empírica;
- média e mediana;
- comparação entre média e mediana;
- outliers;
- quartis, quantis e boxplot;
- dispersão;
- intervalo, variância e desvio padrão;
- escala logarítmica;
- médias geométrica e harmônica.
