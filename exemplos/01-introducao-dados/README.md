# Aula 01: uma primeira tabela

Notebook introdutorio para a primeira aula da disciplina.

## Papel didatico

O notebook mostra como uma pergunta simples se transforma em uma tabela,
variaveis, indicadores e novas perguntas. Ele nao exige arquivos externos.

## Conceitos

- unidade observacional;
- variavel;
- indicador;
- ordenacao;
- limitacoes de uma tabela pequena.
