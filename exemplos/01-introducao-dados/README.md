# Aula 01: uma primeira tabela

Notebook introdutório para a primeira aula da disciplina.

## Papel didático

O notebook mostra como uma pergunta simples se transforma em uma tabela,
variáveis, indicadores e novas perguntas. Ele não exige arquivos externos.

## Conceitos

- unidade observacional;
- variável;
- indicador;
- ordenação;
- limitações de uma tabela pequena.
